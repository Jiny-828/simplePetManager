# 🐾 simplePetManager
**서울 지역 반려동물 시설 정보 통합 플랫폼**

## 📖 프로젝트 개요
* **프로젝트명**: simplePetManager 
* **수행기간**: 2026.03.04 ~ 2026.04.20 (2개월) 
* **목적**: 파편화된 서울시 반려동물 시설(동물병원, 동물약국, 반려동물 호텔 등) 정보를 통합하여 직관적인 위치 기반 검색 및 인프라 확인 서비스 제공 

---

## 🛠 기술 스택
### **Frontend**
* JSP, JSTL (서버사이드 렌더링)
* HTML, CSS, Vanilla JavaScript
* 카카오 지도 API (가게 위치 표시)

### **Backend**
* Java 21, Spring Boot 4.0.4 
* Spring Security (JWT 기반 무상태 인증) 
* MyBatis 4.0.1 (SQL Mapper) 
* MySQL (HikariCP 커넥션 풀) 
* Brevo API (SMTP 이메일 인증) 

### **DevOps & Infra**
* Gradle (빌드, WAR 패키징) 
* Docker (멀티 스테이지 빌드) 
* Render (클라우드 배포) 

---

## 💡 주요 담당 역할 및 구현 내용
### **1. 인증 및 보안 강화**
* **JWT 기반 인증**: Access Token(30분), Refresh Token(14일) 발급 및 삭제 기능 구현
* **이메일 인증**: Brevo API 활용, 6자리 인증코드 발급, 5분 제한 타이머 및 입력 검증 로직 추가
* **접근 제어**: `LoginInterceptor`를 도입하여 비정상적인 접근 경로 리다이렉트 처리 

### **2. 데이터베이스 설계 및 SQL 최적화**
* **테이블 설계**: MyBatis와 연동하여 회원, 시설, 게시글 테이블 구조 설계 
* **SQL 최적화**: `#{}`(파라미터 바인딩)와 `${}`(문자열 치환)의 차이를 이해하고 올바른 바인딩 방식으로 수정 

### **3. 보안 취약점 해결 (방어적 프로그래밍)**
* **캐시 제어**: 브라우저 '뒤로가기'를 통한 민감 정보 노출 방지를 위해 응답 헤더에 `no-cache`, `no-store` 설정 
* **세션 관리**: 비밀번호 수정 페이지에 다단계 접근 제어 구축 및 완료 시 즉시 세션 파기 

---

## 🛠 문제 해결 경험
* **이슈**: 비밀번호 변경 페이지의 세션 유효성 검증 누락으로 인한 보안 취약점 발견 
* **해결**: 서버 사이드 세션 파기와 클라이언트 측 HTTP 캐시 제어(no-store, no-cache)를 병행하여 보안 우회 경로 원천 차단 
* **배운 점**: 정상적인 기능 구현뿐만 아니라 예외적인 사용자 행동 패턴과 브라우저 특성까지 고려한 방어적 프로그래밍의 중요성 체득
